# Main Portfolio

Design portfolio website of Jainam Kapadia, built with plain HTML, CSS and JavaScript.

## Structure

```
CodeFiles/
├── index.html        Home page (hero, work, about, contact)
├── projects/         One HTML page per case study
├── css/style.css     All styles; colors and fonts live in :root
├── js/main.js        Scripts
└── assets/
    ├── images/       Project images and thumbnails
    ├── videos/
    ├── icons/
    └── fonts/
```

## Running locally

Open `CodeFiles/index.html` in a browser, or use the VS Code "Live Server" extension for auto-reload.
