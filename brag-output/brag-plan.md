# Brag plan: Adaptive Cluster (HMI concept, Jainam Kapadia)

**What it is:** an instrument cluster that changes with the drive: a highway mode and a traffic mode, with alerts only when they matter.
**For:** drivers in overload; the audience for the video is recruiters and studios looking at Jainam's HMI work.
**What sets it apart:** each warning is designed from the sensor up (what the car detects, then what the driver sees), and the layout switches by driving context.
**Hook:** the research finding, "Important alerts get buried.", after "Your dashboard shows everything."
**Real UI shown:** Jainam's own Figma screens (12 exported states). They are cross-faded in place, so the cluster appears to change state live.
**Tone:** polished, night-drive cinematic. Site palette (night #0B0D12, taillight red #FF3B30, dusk #FFB38A), Archivo condensed, Geist Mono labels, corner-bracket frames.
**Share line:** "Your dashboard shows everything, so the alert that matters gets buried. Adaptive Cluster changes with the drive."
