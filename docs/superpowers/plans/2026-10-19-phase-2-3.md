# Phase 2 (design system) + Phase 3 (skeleton) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static Astro site in `CodeFiles/` with the full design system on `/system` and a no-motion version of every page, filled with placeholder content.

**Architecture:** Astro static output, plain CSS in `@layer`s, with tokens as custom properties. Components are `.astro` files with zero client JS, except tiny inline scripts for the theme toggle, copy-email and the grid overlay. Content comes from content collections, and pages read only from them. Cross-document View Transitions are enabled with CSS alone.

**Tech Stack:** Astro 6.4.8 (Node 22.19 here; Astro 7 needs ≥22.22). Self-hosted Archivo variable (wdth + wght) and Geist Mono 400. `<model-viewer>` 4.x, lazy, `/car` only.

**Spec:** `PORTFOLIO_PROMPT.md`, overridden by the decisions in memory `portfolio-decisions` (dark default, red accent, car page off-nav, small Enrico-style cards).

## Global Constraints
- JS ≤ 40 KB gz on first load (target ~2 KB). Fonts ≤ 2 families, ≤ 4 files. No WebGL except `/car`.
- Phase 3 has **no motion** beyond hover and focus colour changes. Reduced motion is honoured anyway.
- WCAG 2.2 AA: skip link, landmarks, visible focus in the accent, contrast ≥ 4.5:1 (checked, not assumed).
- Radius 0, hairlines instead of shadows, one accent at about 1% coverage.
- Adding a project = copying one Markdown file in `src/content/projects/`. No code edits.
- Nav: `Index, Work, About, Contact`. `/car` is reachable only from the Home card. `/system` is unlinked.

## Review Focus
1. JS disabled: every page readable, the theme follows the system, and copy-email falls back to `mailto:`.
2. A project with no cover image, or a placeholder → the `Placeholder` block renders at the declared ratio (no layout shift).
3. A long title or name at 320px wide → no horizontal scroll.
4. Keyboard only: skip link first, focus visible on every link and button, `G` toggles the overlay, `Esc` closes the menu.
5. Light/dark toggle persists across pages, with no flash of the wrong theme (inline head script).
